# External Integrations

**Analysis Date:** 2026-02-13

## APIs & External Services

**GitHub:**
- GitHub CLI (gh) - Installed via Homebrew in `install/Brewfile`
- GitHub Actions - CI/CD workflow in `.github/workflows/dotfiles-installation.yml` for weekly testing
  - Runs on macOS 13, 14, 15 via GitHub-hosted runners
  - Triggers on push and weekly schedule (Thursday 5:00 PM UTC)

**Package Repositories:**
- Homebrew Package Index - Core packages installed via `install/Brewfile` and `install/Caskfile`
- npm Registry - Global Node packages from `install/npmfile`
- Cargo Registry - Rust crates from `install/Rustfile`
- APT Repository - Ubuntu/Debian packages via system package manager

**Remote Resources:**
- NVM Installation: Auto-download from https://raw.githubusercontent.com/nvm-sh/nvm in `system/.nvm` and Makefile
- Zim Framework: Auto-download from https://raw.githubusercontent.com/zimfw/zimfw in `runcom/.zshrc`
- Bun Runtime: Installation from https://bun.sh/install in Makefile (target: `make bun`)
- Rustup: Installation from https://sh.rustup.rs in Makefile (target: `rust-packages-linux`)

## Data Storage

**Databases:**
- Not used - personal dotfiles only

**File Storage:**
- Local filesystem only
- XDG Base Directory compliant paths in `system/.env`:
  - `~/.config` - Application configurations
  - `~/.cache` - Cache files and completion caches
  - `~/.local/share` - Data files (pnpm, runtime files)

**Caching:**
- Dircolors cache: `$XDG_CACHE_HOME/dircolors.sh` generated by `system/.path`
- Zsh completion cache: `~/.zcompcache` configured in `runcom/.zshrc`
- Zsh dump: `~/.zcompdump` configured in `runcom/.zshrc`
- Homebrew cache: Managed by Homebrew, cleaned via `dot clean`
- Cargo cache: Managed by cargo-cache tool, cleaned via `dot clean`
- pip cache: Cleaned via `dot clean`
- gem cache: Cleaned via `dot clean`

## Authentication & Identity

**Git:**
- SSH keys via OS keychain/credential storage
  - macOS: osxkeychain helper configured in `config/git/config`
  - Linux/WSL: Manual SSH key setup required
- GitHub user configuration in `config/git/config`:
  - User name and email set during post-installation
  - GitHub username stored as `[github] user`

**Custom Tokens:**
- Manual entry point: `system/.exports` file
- Tokens stored locally by user as environment variables
- Never committed to repository (in `.gitignore`)

## Monitoring & Observability

**Error Tracking:**
- Not integrated - personal tool

**Logs:**
- Shell history: Bash/Zsh history files configured in `system/.env`
- Makefile logging: Installation output from package managers
- Test output: bats test framework output to stdout in `test/`
- No centralized logging - local file-based history

**Terminal/Shell Debugging:**
- shellcheck - Shell script linting in `install/Brewfile`
- Manual testing via test scripts in `test/verify-setup.sh`

## CI/CD & Deployment

**Hosting:**
- GitHub repository - https://github.com/sunnypatel/dotfiles
- Distributed via remote installation script: `remote-install.sh`

**CI Pipeline:**
- GitHub Actions workflow in `.github/workflows/dotfiles-installation.yml`
  - Tests on macOS 13, 14, 15 weekly
  - Cleans environment, runs installation, verifies setup
  - Runs full test suite with bats on macOS

**Deployment Method:**
- Manual pull from GitHub via `git clone`
- Automated setup via `remote-install.sh` script
- Makefile-driven installation targets

## Environment Configuration

**Required env vars:**
None required for core functionality. Optional configuration variables:

- `DOTFILES_DIR` - Root directory of dotfiles (auto-detected, fallback to `~/.dotfiles`)
- `HOMEBREW_PREFIX` - Homebrew installation path (auto-detected)
- `NVM_DIR` - Node Version Manager directory (default: `~/.nvm`)
- `EDITOR` - Text editor for git (default: `code`, set in `system/.env`)
- `VISUAL` - Visual editor (default: `code`, set in `system/.env`)
- `XDG_CONFIG_HOME` - User config directory (default: `~/.config`)
- `XDG_CACHE_HOME` - User cache directory (default: `~/.cache`)
- `XDG_DATA_HOME` - User data directory (default: `~/.local/share`)
- `LC_ALL`, `LANG` - Locale settings (configured in `system/.env`)

**Secrets location:**
- `system/.exports` - User-created file for personal tokens and secrets
  - Not committed (in `.gitignore`)
  - Referenced in `.bash_profile` loading sequence
  - Created manually by user during post-installation

## Webhooks & Callbacks

**Incoming:**
- None - personal dotfiles application

**Outgoing:**
- Git push/pull to GitHub repository
- GitHub Actions workflow triggers on push events

## External Tool Integration

**macOS-Specific:**
- Dock management via `duti` utility for setting default applications
- System defaults configuration via `defaults` command in `macos/defaults*.sh`
- Alfred app installation via Caskfile (commented in current config)

**Terminal Applications:**
- Alacritty: Cross-platform terminal emulator configuration in `config/alacritty/`
- Fork: Git client (Caskfile)
- Cursor: Code editor (Caskfile, replaces VSCode)
- Firefox, Google Chrome: Web browsers (Caskfile)

**Development Integrations:**
- Visual Studio Code: Editor and git mergetool/difftool in `config/git/config`
- Git Delta: Enhanced diff in `config/git/config`
- The Fuck: Command correction utility configured in `config/thefuck/settings.py`
- Topgrade: Universal package manager update tool used in `bin/dot update`
