```

  $DOTFILES_DIR/bin        # <-- REMOVE THIS LINE
  $HOME/.cargo/bin
  ...
)
```

Remove ONLY the `$DOTFILES_DIR/bin` line. Keep everything else exactly as-is. The platform detection in .zsh_path (HOMEBREW_PREFIX via OSTYPE) is correct and stays.

Also remove `$HOME/.cargo/bin` from the path array -- Rust/Cargo is out of scope per PROJECT.md. And remove `$HOME/.local/share/pnpm`, `$HOME/.bun/bin`, `$HOME/.deno/bin` -- these are all tool-specific paths for tools this dotfiles repo does not manage. They were leftovers from the old bloated setup.

The cleaned path array should be:
```
path=(
  $HOME/.local/bin
  ${HOMEBREW_PREFIX:+$HOMEBREW_PREFIX/bin}
  ${HOMEBREW_PREFIX:+$HOMEBREW_PREFIX/sbin}
  /usr/local/bin
  /usr/bin
  /bin
  /usr/sbin
  /sbin
  $path
)
```

Add `$HOME/.local/bin` (standard user binary location, replaces $DOTFILES_DIR/bin as the user-local PATH). This was not in the old config but is the standard XDG location for user binaries.

Use `git rm -r bin/` to remove the entire directory so git tracks the deletion.
