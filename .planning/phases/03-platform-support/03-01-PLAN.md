<task type="auto">
  <name>Task 2: Rewrite Makefile with inline platform detection</name>
  <files>Makefile</files>
  <action>
Completely replace the current Makefile. The existing one is stale (references deleted `runcom/`, `config/` directories, uses `bin/is-supported` scripts, installs bash, nvm, java, rust, bun, etc.). Write a new Makefile from scratch.

The new Makefile must:

1. **Detect platform via inline `uname`** (not external scripts):
```makefile
DOTFILES_DIR := $(shell dirname $(realpath $(firstword $(MAKEFILE_LIST))))
UNAME_S := $(shell uname -s)
UNAME_M := $(shell uname -m)

ifeq ($(UNAME_S),Darwin)
    OS := macos
    ifeq ($(UNAME_M),arm64)
        BREW_PREFIX := /opt/homebrew
    else
        BREW_PREFIX := /usr/local
    endif
else ifeq ($(UNAME_S),Linux)
    IS_WSL := $(shell grep -qi microsoft /proc/version 2>/dev/null && echo true || echo false)
    ifeq ($(IS_WSL),true)
        OS := wsl
    else
        OS := linux
    endif
    BREW_PREFIX := /home/linuxbrew/.linuxbrew
endif
```

2. **Use `:=` (simple expansion)** for all `$(shell ...)` variables. Never `=`.

3. **Define these .PHONY targets:**
   - `all` -> dispatches to `$(OS)` target
   - `macos` -> `install-brew install-packages stow-packages`
   - `linux` -> `install-brew install-packages stow-packages`
   - `wsl` -> `linux` (WSL2 is treated as Linux per research recommendation)
   - `install-brew` -> Install Homebrew if not present (same curl command for macOS and Linux)
   - `install-packages` -> `brew bundle --file=$(DOTFILES_DIR)/Brewfile` (references root Brewfile, NOT install/Brewfile)
   - `stow-packages` -> `stow -d $(DOTFILES_DIR)/stow -t $(HOME) zsh git tmux nvim` (GAP-01 fix: must use -d and -t flags)
   - `unlink` -> `stow -d $(DOTFILES_DIR)/stow -t $(HOME) -D zsh git tmux nvim` (unstow)

4. **Linux prerequisite handling:**
   - The `linux` target (and `wsl` via linux) should call `install-deps` before `install-brew`
   - `install-deps` runs: `sudo apt-get update && sudo apt-get install -y build-essential curl git` (minimal prerequisites for Homebrew on Linux)
   - On macOS, `install-deps` is a no-op (macOS has Xcode CLT)

5. **Do NOT include any of these** (they are from the old Makefile and are out of scope):
   - No `bash` target, no `npm`/`nvm` targets, no `rust`/`cargo` targets
   - No `java` target, no `bun` target, no `duti` target
   - No `sudo` keepalive trick, no `SHELLS` variable
   - No `cask-apps` target (no casks in Brewfile)
   - No `apt-packages` target with 17 packages (Homebrew handles packages on Linux)
   - No `vscode-extensions` target
   - No `NVM_DIR`, `SHELL`, `ACCEPT_EULA` exports
   - No `test` targets (Phase 5 scope)
   - No references to `runcom/`, `config/`, `bin/` directories

6. **Keep under 50 lines** (INS-04 from Phase 4 roadmap -- get ahead of it).

7. **Use POSIX sh in recipes** (do NOT set `SHELL := /bin/bash`). The default `/bin/sh` is most portable.

8. **Add a brief header comment** explaining what the Makefile does and supported platforms.

Write this as the complete file, not a patch. The old Makefile is entirely replaced.
