  <action>
    Create the git/ Stow package at `git/.config/git/` mirroring the XDG location `~/.config/git/`.

    1. Create directory: `mkdir -p git/.config/git`

    2. Move existing config: `git mv config/git/config git/.config/git/config`

    3. Move existing ignore: `git mv config/git/ignore git/.config/git/ignore`

    4. Edit `git/.config/git/config` to curate settings (requirements GIT-01, GIT-02, GIT-03):

       **Keep (curated aliases - GIT-01):**
       - All aliases in the [alias] section — these are the user's curated git aliases
       - Remove duplicate `d` alias (there are two definitions, keep the more useful one)
       - Remove duplicate `go` alias (there are two definitions, keep the simpler one: `"!f() { git checkout -b \"$1\" 2> /dev/null || git checkout \"$1\"; }; f"`)

       **Update (core settings - GIT-02):**
       - Change `editor = code --wait` to `editor = nvim` (project uses neovim now)
       - Change `excludesfile = ~/.config/git/ignore` — keep as-is, this is already XDG-compliant
       - Remove `pager = delta` from [core] — delta is being removed (CLN-02). Use default pager.
       - Remove entire `[delta]` section — delta tool being removed
       - Remove `[credential] helper = osxkeychain` — too platform-specific for the config file. macOS will auto-detect credential helper.
       - Remove `[difftool "vscode"]` and `[mergetool "vscode"]` sections — switching to nvim
       - Update `[diff] tool = vscode` to `tool = nvimdiff`
       - Update `[merge] tool = vscode` to `tool = nvimdiff`
       - Remove `[difftool] prompt = false` and `[mergetool] prompt = false` — nvimdiff doesn't need these

       **Keep as-is (core settings - GIT-02):**
       - [user] section (name, email)
       - [github] section
       - [core] filemode, trustctime, autocrlf, untrackedCache, ignorecase
       - [pull] rebase = true
       - [rerere] enabled = true
       - [rebase] autoStash = true
       - [init] defaultBranch = main
       - [push] default = simple, followTags = true
       - [fetch] prune = true
       - [grep] lineNumber = true
       - [help] autocorrect = 1
       - [diff] renames, indentHeuristic, colorMoved
       - [merge] conflictstyle, defaultToUpstream
       - [color] ui = auto
       - [versionsort] suffixes
       - [advice] detachedHead = false

    5. Verify `git/.config/git/ignore` has sensible patterns. The existing file is fine — keep it as-is.

    IMPORTANT: After moving, `config/git/` directory should be empty. Do NOT remove config/ directory yet — tmux files are still there, and other unused configs (alacritty, prettier, thefuck, topgrade) will be removed in Plan 04.

  <action>
    Create the tmux/ Stow package at `tmux/.config/tmux/` mirroring the XDG location `~/.config/tmux/` (supported by tmux 3.2+, requirement TMX-02).

    1. Create directory: `mkdir -p tmux/.config/tmux`

    2. Move gpakosz base config: `git mv config/tmux/tmux.conf tmux/.config/tmux/tmux.conf`
       This is the gpakosz/.tmux base file (~80KB). Do NOT edit it — it's meant to be immutable upstream (requirement TMX-01).

    3. Move user customizations: `git mv runcom/tmux.conf.local tmux/.config/tmux/tmux.conf.local`
       This is the user's customization file with gpakosz tmux_conf_* variables.

    4. The gpakosz tmux.conf sources tmux.conf.local with a line like:
       `source-file ~/.tmux.conf.local` or `source-file "$HOME/.tmux.conf.local"`

       Check the tmux.conf file for this source line. If it references `~/.tmux.conf.local` (legacy location), it needs updating to `~/.config/tmux/tmux.conf.local`. However, since we are NOT supposed to edit tmux.conf (immutable upstream), instead check if tmux.conf already handles the XDG case. If not, we have two options:

       a) If tmux.conf references the legacy path: The file itself handles sourcing. Since gpakosz/.tmux may not have been updated for XDG, the source path might point to `~/.tmux.conf.local`. In that case, add a note in tmux.conf.local at the top explaining the user should periodically update tmux.conf from upstream. For now, we may need to update the source-file line in tmux.conf to point to `~/.config/tmux/tmux.conf.local` — this is the one acceptable edit to the gpakosz file for XDG migration.

       b) If tmux.conf already handles XDG: no changes needed.

       Search for `source.*tmux.conf.local` in tmux.conf and update the path if it points to legacy location.

    5. Also search tmux.conf for any `~/.tmux.conf` self-references (like the `bind e` edit keybinding) and update those to `~/.config/tmux/tmux.conf` if found.

    After this, `config/tmux/` should be empty and `runcom/` should be empty. Do NOT remove runcom/ or config/ directories yet — Plan 04 handles cleanup.
