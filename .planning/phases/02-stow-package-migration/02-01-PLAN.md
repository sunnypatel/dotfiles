  <action>
    Create the zsh/ Stow package directory structure that mirrors the home directory:

    1. Create directories: `mkdir -p zsh/.config/zsh`

    2. Create `zsh/.zshenv` — this file lives at `~/.zshenv` after stowing. It MUST:
       - Set XDG base directory variables (XDG_CONFIG_HOME, XDG_DATA_HOME, XDG_CACHE_HOME, XDG_STATE_HOME)
       - Set `export ZDOTDIR="${ZDOTDIR:-$XDG_CONFIG_HOME/zsh}"` so Zsh reads .zshrc from ~/.config/zsh/
       - Set essential env vars: DOTFILES_DIR, EDITOR (nvim), VISUAL, LANG, LC_ALL
       - Set terminal env vars: CLICOLOR, GREP_COLORS, MANPAGER
       - Handle macOS ulimit
       - Source .zsh_path using ZDOTDIR: `source "${ZDOTDIR:-$XDG_CONFIG_HOME/zsh}/.zsh_path"`
       - Keep `skip_global_compinit=1` at the top
       - IMPORTANT: The source path for .zsh_path must use ZDOTDIR (not the Phase 1 pattern of `${0:a:h}`), because after stowing, .zshenv lives at ~/.zshenv and .zsh_path lives at ~/.config/zsh/.zsh_path

    3. Move `runcom/.zshrc` -> `zsh/.config/zsh/.zshrc` using `git mv`. The file content stays the same — source paths already use `${ZDOTDIR:-$HOME}` which will correctly resolve to ~/.config/zsh/ once ZDOTDIR is set.

    4. Move `runcom/.zimrc` -> `zsh/.config/zsh/.zimrc` using `git mv`.

    5. Move `runcom/.zsh_path` -> `zsh/.config/zsh/.zsh_path` using `git mv`.

    6. Move `runcom/.zsh_aliases` -> `zsh/.config/zsh/.zsh_aliases` using `git mv`.

    7. Move `runcom/.zsh_functions` -> `zsh/.config/zsh/.zsh_functions` using `git mv`.

    8. Move `system/.dir_colors` -> `zsh/.config/zsh/.dir_colors` using `git mv`. This migrates the dir_colors file into the zsh package as decided in Phase 1 ("Keep system/.dir_colors for Phase 2 evaluation"). Add a line to .zshrc to source it: `[[ -f "${ZDOTDIR:-$HOME}/.dir_colors" ]] && eval "$(dircolors "${ZDOTDIR:-$HOME}/.dir_colors")"` (only on Linux, macOS uses LSCOLORS). Wrap in platform check.

    9. Create new `runcom/.zshenv` is NOT needed — we are replacing runcom/ entirely. The old runcom/.zshenv file becomes zsh/.zshenv via content rewrite (not move, since the content changes significantly with ZDOTDIR addition).

    IMPORTANT: Use `git mv` for moves to preserve git history. For .zshenv, since the content changes substantially (adding ZDOTDIR), first `git mv runcom/.zshenv zsh/.zshenv` then edit the file in place.

    After all moves, runcom/ should contain ONLY `tmux.conf.local` (which Plan 02 will handle).
